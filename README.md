# 🌦 Weather App

[![Download APK](https://img.shields.io/badge/Download-APK-green?style=for-the-badge)](https://github.com/debasissau/my-Weather-App/releases/download/v1.0/myWeather.apk)

A modern and scalable Weather Application built using **Kotlin** and **Jetpack Compose**.
The app fetches real-time weather data from a REST API and displays it in a clean, user-friendly interface.

---

## 🚀 Features

* 🌍 Real-time weather updates
* 📍 Location-based weather data
* 🎨 Modern UI with Jetpack Compose
* ⚡ Fast and smooth performance
* 🧩 MVVM architecture
* 🌐 API integration using Retrofit


---

## 🛠 Tech Stack

* **Language:** Kotlin
* **UI:** Jetpack Compose
* **Architecture:** MVVM
* **Networking:** Retrofit
* **API:** OpenWeatherMap
